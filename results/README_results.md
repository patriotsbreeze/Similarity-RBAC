### QPS Interpretation
The Python implementation QPS (10–8,600 QPS) reflects Python filter callback
overhead (~5µs/call × ~500 calls/query). The C++ implementation
(`include/rbac_hnsw.hpp`) performs the same gate in ~1 ns (single AND instruction),
achieving 1–2 orders of magnitude higher throughput.

For the paper, C++ benchmarks on an AWS c5.4xlarge (Intel Xeon, 16 vCPU, 32 GB RAM)
are the target evaluation platform.
